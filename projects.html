2D FEM Solver

March 2026

A lightweight Python finite element method package for structural analysis. The project provides capabilities for static analysis, modal analysis, and forced vibration simulations. It supports two-node beam and truss elements and includes dynamic analysis based on a diagonal damping matrix. The dynamic response is computed using the reduced order Modal Response Method and results are retrieved through the Mode Displacement Method.

Spacecraft Orbital Mechanics

October 2025 - January 2026

Design of spacecraft interplanetary transfer; modeling and analysis of closed-orbit perturbations using cartesian propagation and Gauss planetary equations.
My main contribution included developing an interplanetary transfer from Venus to Earth to an asteroid using the patched-conics approach while minimizing the total ΔV. For this purpose, a multi-step pruned grid-search algorithm was implemented.
